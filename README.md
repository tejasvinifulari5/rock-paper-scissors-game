# Rock Paper Scissors Game

A modern and responsive Rock Paper Scissors game built using:

- HTML
- CSS
- JavaScript

## Features

- Responsive UI
- Smooth animations
- Match winner system
- Round tracker
- Reset functionality
- Modern glassmorphism design
